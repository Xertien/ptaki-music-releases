# Ptaki Musique — versions

Les applications de Ptaki Musique, prêtes à installer. Chaque version publiée
se trouve dans [Releases](https://github.com/Xertien/ptaki-music-releases/releases).

| Plateforme | Fichier |
|---|---|
| Windows | `Ptaki Musique_<version>_x64-setup.exe` (ou `.msi`) |
| Linux | `.AppImage`, `.deb` ou `.rpm` |
| Android (téléphone) | `ptaki-musique-<version>-mobile-universal.apk` |
| Android TV | `ptaki-musique-<version>-tv-universal.apk` |

L'application de bureau se met à jour toute seule à partir de ce dépôt.
`SHA256SUMS` donne l'empreinte de chaque fichier pour vérifier un téléchargement.

Ce dépôt ne contient que les applications : il faut un serveur Ptaki Musique
pour s'en servir.
